# Mega City Tours & Travells

Marketing website for Mega City Tours & Travells, a Hyderabad-based vehicle rental and group travel operator: fleet, services, tour packages, gallery, blog, FAQs and a quote request form that hands off to WhatsApp.

Live site: https://megacitytoursandtravels.com

## Tech stack

- [TanStack Start](https://tanstack.com/start) (React 19, file-based routing via TanStack Router, SSR)
- [Vite 7](https://vite.dev)
- [Tailwind CSS 4](https://tailwindcss.com) with [shadcn/ui](https://ui.shadcn.com) components (Radix UI primitives)
- TypeScript
- Deployed to [Cloudflare Workers](https://developers.cloudflare.com/workers/) via `@cloudflare/vite-plugin`

## Project layout

```
src/
  routes/       Pages (one file per route; __root.tsx holds the shared <head> and layout)
  components/   Site components; components/ui holds the shadcn/ui primitives
  data/         Site content: vehicles, services, packages, blogs, FAQs, contact details
  styles.css    Tailwind entry and theme tokens
public/         Static assets served as-is (favicons, OG images, robots.txt, sitemap.xml, video)
```

`src/routeTree.gen.ts` is generated by the TanStack Router plugin; don't edit it by hand.

## Local development

Requires [Bun](https://bun.sh) (the repo also includes a `package-lock.json`, so npm works too).

```sh
bun install        # install dependencies
bun run dev        # start the dev server on http://localhost:8080
bun run build      # production build into dist/
npx wrangler dev   # serve the production build locally in the Workers runtime (run after build)
bun run lint       # ESLint
bun run format     # Prettier
```

### Environment variables

| Variable                     | Required | Purpose                                                                                                                                                                  |
| ---------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `VITE_GOOGLE_PLACES_API_KEY` | No       | Enables Google Places suggestions in the location fields. Without it, the form falls back to the built-in Hyderabad/Telangana list in `src/data/locationSuggestions.ts`. |

Put local values in `.env.local` (git-ignored).

## Deployment

The site runs as a Cloudflare Worker named `mega-city-journeys` (see `wrangler.jsonc`).

`bun run build` writes the Worker to `dist/server/` and static assets to `dist/client/`, along with the deploy config Wrangler needs. To deploy manually:

```sh
bun run build
npx wrangler deploy
```

If the repository is connected to Cloudflare Workers Builds, pushes to the production branch build and deploy automatically. Set the build command to `bun run build` and the deploy command to `npx wrangler deploy`.

Canonical URLs, the sitemap and Open Graph tags point at `https://megacitytoursandtravels.com`. Update them in `src/routes/`, `public/sitemap.xml` and `public/robots.txt` if the domain changes.
